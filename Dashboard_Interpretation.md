# GRC Dashboard — How to Explain It
The workbook consolidates simulated control status, inherent risk ratings and open remediation actions. Dashboard metrics use Excel formulas so they can update when you change source tables.

## Questions it answers
- What fraction of assessed controls are implemented, partial or planned?
- How many critical/high risks require management attention?
- How many corrective actions are still open?

## Limitations
This is a **selected-control assessment** of a fictional company. A count of implemented controls is not a formal compliance percentage. Statuses are assumed until validated with evidence; risk ratings use a local project scale. Export a dashboard screenshot from Excel after reviewing formulas and values.
