## Important disclosure
This repository contains **simulated data and example documentation**. No actual client records, AWS configuration screenshots, SOC 2 audit, ISO certification or independently verified findings are represented. Do not upload credentials, personal data or unredacted screenshots.

## How to use
Open each folder's README, inspect the Excel files, review its Markdown reports, and run through the suggested interview explanation. Excel formulas should be recalculated when opened in Excel/Sheets. Where real validation is required, collect your own authorized, redacted evidence and update the status.

'I developed seven simulated GRC projects for a fictional SaaS company, covering ISO 27001 control assessment, risk scoring, vendor due diligence, incident response, SOC 2 cloud mapping, management reporting and a mock audit.
